# Welcome to the FLIN Community Network Hub! 🧠

Welcome! FLIN is an open-source experiment in **source-grounded associative memory**, directed links, and pulse-based recall. Its original desktop reference application currently builds **mathematics-specific knowledge networks**. Researchers are encouraged to fork and adapt it for other areas while explaining which parts they changed.

### How you can participate

- **Share a network:** create a **Network Showcase** discussion with a public `.sqlite3` download link, SHA-256, source notes, and FLIN/fork compatibility.
- **Explore and reproduce:** download somebody else's compatible network, import it into a separate local FLIN network, and report your results.
- **Ask difficult questions:** identify theoretical assumptions, test pulse dynamics, report negative results, or propose improvements in **Research & Experiments** and **Ideas & Theories**.
- **Extend to another domain:** show your fork in **Domain Extensions** and explain its schema and data-processing changes.
- **Ask for help:** use **Help & Questions** for installation, network imports, or other practical issues.

### Where are the downloads?

**Community-shared networks:** [Network Showcase / Discussions](https://github.com/jjy246/FLIN-Research-Desktop/discussions). Contributors host their own assets, usually via GitHub Releases in their own repositories.

**Officially reviewed snapshots and apps:** [FLIN Releases](https://github.com/jjy246/FLIN-Research-Desktop/releases). Maintainers manually review a separate [Network Submission Issue](https://github.com/jjy246/FLIN-Research-Desktop/issues/new?template=network_submission.yml) before republishing a community snapshot.

A posted or reviewed memory network is **not** a scientific validation or mathematical proof. Please respect data permissions, privacy, reproducibility, and each other's work.
