# Optional public launch announcement (edit before posting)

> FLIN — Feature-Link Intelligence Network — is now open source!
>
> FLIN is an **experimental, mathematics-specific** desktop reference
> implementation of source-grounded memory units and weighted **directed**
> pulse associations. It is not a validated cognitive model and does not prove
> mathematical statements.
>
> You can read the architecture and theory, run the source code on Windows,
> macOS or Linux, inspect the storage design, reproduce the offline example,
> and fork the software for new knowledge domains.
>
> We welcome theoretical criticism, reproducible experiments, pull requests,
> and shared SQLite memory networks. Network submissions are reviewed before
> official publication in GitHub Releases. Other-domain forks are especially
> welcome, with explicit compatibility notes.
>
> Project: https://github.com/jjy246/FLIN-Research-Desktop
> Start here: README → User Guide → FLIN Theory → Porting Other Domains.
