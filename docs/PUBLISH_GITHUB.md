# Publishing FLIN as an open-source GitHub project

**Use the maintained and complete [Open-source launch checklist](OPEN_SOURCE_LAUNCH.md)**
for account authentication, fresh Git initialization, creating the public
`jjy246/FLIN-Research-Desktop` repository, GitHub Actions, native artifacts,
network exports, official Releases and community network approvals.

The executable FLIN application remains the **mathematics-specific reference
implementation**. It has **not** been modified to handle every knowledge
domain. Other contributors may fork it and adapt their own code, following
[Porting FLIN to other domains](PORTING_OTHER_DOMAINS.md).

The source repository is **Apache-2.0 open source** (`LICENSE`). Release
assets may include binary desktop builds or approved `.sqlite3` networks.
SQLite is not automatically Apache-2.0 licensed; source-data permissions must
be checked independently. GitHub releases are manual publication steps unless
an additional workflow is explicitly introduced in the future.
